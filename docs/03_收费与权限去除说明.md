# 收费 / 权限门槛分析与"全开放"实现说明

> 目标：让复刻版 **所有原本可能收费/受限的功能一律免费开放，无任何权限设置**。

---

## 1. 原程序中的门槛证据

在 `navicat.exe` / `libcc.dll` 的字符串与符号中可检出与授权相关的标识（示例）：

| 标识 | 含义 |
|---|---|
| `nlsTrialExpired` | 试用到期提示文案 |
| `isInTrialPeriodNow` | 当前是否处于试用期 |
| `trialEnabled` | 试用是否启用 |
| `license` / `licenseKey` | 许可证/激活码 |
| `subscription` | 订阅 |
| `Premium` / `PremiumSuite` | 高级/套件版本标识 |
| `AppFeature*`（92 项） | 特性开关，用于按版本/订阅裁剪能力 |

**结论**：Navicat 用 `AppFeature` 特性枚举 + 许可证/试用判定来裁剪"哪些功能可见/可用"。这属于**客户端授权层**，而非数据能力本身；数据库连接与绝大多数本地工具的能力都随客户端一同下发。

---

## 2. 复刻版的处理策略

复刻版从设计上**彻底移除授权层**，实现"无条件全开放"：

1. **不存在任何登录/注册/激活流程**。首次启动即进入主界面，自动创建本地示例库。
2. **不存在试用期判断**。代码中无 `trial/license/subscription/entitlement/quota` 相关逻辑分支。
3. **不存在特性开关裁剪**。所有页面（含 ER、图表、报表、AI、自动化、数据生成、数据剖析、数据字典、导入导出、传输、监控、用户与权限等）在菜单/工具栏**默认全量可见、可直接打开**。
4. **不存在角色/权限校验**。"用户与权限"页仅作展示，并**显式注明：全部权限已开放、不设任何用户/角色/权限限制**（该页权限列统一显示"全部"）。
5. **不接入任何云端计费后端**。无账号、无 token、无网络鉴权；除"连接 SQLite 文件/本机操作"外不产生任何外部请求。

## 3. 代码级核验（可自证）

对复刻工程 `src/**/*.rs` 全文检索授权相关关键字：

```powershell
Select-String -Path F:\codex工作区\navicat-rs\src\*.rs,F:\codex工作区\navicat-rs\src\ui\*.rs `
  -Pattern "paywall|subscription|\blicense\b|trial|entitlement|isLoggedIn|\blogin\b|quota|premium" -CaseSensitive:$false
```

预期：**无功能性授权命中**（唯一会命中的是产品名 "Navicat Premium 18" 的展示文案，非逻辑分支）。授权相关实现分支为 **0**。

> 备注：实测中对 `stripe`/`striped` 做宽松匹配会命中 UI 网格属性 `striped(true)`（斑马纹），这是**假阳性**，与支付无关。用上面的词边界写法可避免。

## 4. 与原版的行为差异（有意为之）

| 维度 | 原版 Navicat | 复刻版 |
|---|---|---|
| 首次启动 | 引导新建连接 / 可能提示试用 | 直接进入主界面，自动创建"示例数据库(SQLite)" |
| 高级功能 | 依版本/订阅显示或灰显 | 全部默认可见可用 |
| 用户权限 | 可对用户/角色授予/回收权限 | 展示"全部开放"，无权限系统 |
| 联网 | 云端工作区可能需要账号 | 完全本地，无需联网 |
| 状态栏 | 版本/许可信息 | 固定显示"全部功能已解锁 · 免费开放 · 无任何权限限制" |

## 5. 合规声明

本复刻为**功能研究与界面参考用途**的独立实现，不包含、不调用、不分发原 Navicat 的任何二进制、许可证或云端服务。所有"解锁/全开放"均指**复刻工程自身没有任何授权限制**，与绕过原软件授权无关。
