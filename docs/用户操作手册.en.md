# navicat-rs User Manual

> Applies to v0.1.0+.
> A guide for end users: launch, UI, connections, tables, SQL, design/modeling, data transfer, ops tools and FAQ.
> Overview: [README](../README.en.md). Changes: [CHANGELOG](../CHANGELOG.md).

---

## 1. Overview

navicat-rs is a **cross-platform single-file** database management desktop client written in **Rust + egui/eframe**, with an interface and workflow referencing Navicat Premium 18. **All features are free and open — no login, trial, or license/permission limits**; local-first, no cloud.

---

## 2. Install & Launch

### Windows (recommended)
1. Download the `navicat-rs` executable (or zip) from [Releases](https://github.com/shuying-code/navicat-rs/releases).
2. **Double-click to run** — no install (single green binary, embedded CJK font).
3. If SmartScreen blocks it: "More info → Run anyway".

### macOS / Linux
macOS uses the universal binary (Intel/Apple Silicon); Linux uses the x64 package (needs system GUI libs). The GUI requires a desktop environment.

### CLI arguments
| Argument | Meaning |
|---|---|
| (none) | Launch GUI |
| `--selftest` | Headless self-test, prints `[PASS]/[FAIL]`, exit code 0 = all pass |

---

## 3. UI Overview

Three-area layout: **menu bar / toolbar / tab bar / left connections & object tree / right function pages / status bar**.

- **Left object tree**: `connection → tables / views / backups / models / users`; zoomable (`− 100% ＋`, `Ctrl+wheel`, settings slider), collapsible per group.
- **Multi-tab**: table, query, designer, ER, builder and tool pages open in parallel.
- **Multi-theme**: `View → Theme` or `Settings → Theme`; the choice persists.

---

## 4. First Use

On first launch a "Sample Database (SQLite)" is created automatically (4 tables + 1 view + demo data).
1. Double-click a table under "Sample Database" to browse.
2. The top toolbar opens query / design / ER / query builder / transfer / import / export / backup / monitor / chart / profile / AI pages.

---

## 5. Connection Management

- New connection: choose engine, host, port, database, user, password (see README "Database Backends").
- **SQLite**: fully real (connection, query, CRUD, DDL, scripts, foreign keys, PRAGMA; `rusqlite` bundled).
- **PostgreSQL**: real network protocol (connection test + real queries).
- Others (MySQL/MariaDB/Oracle/SQL Server/MongoDB/Redis/Snowflake/DM/ODBC): connection config + offline demo schema (full UI/workflow).

---

## 6. Data Tables

- **Browse**: paging, filtering, sorting (click headers).
- **Edit**: inline cell editing, insert/delete rows.
- **Export**: export the current table's data.

---

## 7. SQL Query

- Multi-statement execution, `Ctrl+Enter` to run.
- Multiple result grids, elapsed time / row count.
- **Explain** plan tree; **SQL prettify**; SQL outline / refactor suggestions; query history.

---

## 8. Design & Modeling

- **Table designer**: column editing → DDL generation.
- **ER diagram**: visualize entity relationships.
- **Query builder**: graphical query composition.
- **Model designer**: conceptual / logical / physical models with reverse engineering, compare, sync.

---

## 9. Data Movement

- **Data transfer**: column mapping + WHERE filtering.
- **Data sync / structure sync**.
- **Import wizard**: CSV / JSON / SQL.
- **Export wizard**: CSV / JSON / SQL / HTML.
- **Data pump**: whole-DB / single-table SQL export.

## 10. Ops & Enhancements

- Server monitor, data profiling, schema analysis, data generation, data masking.

## 12. Workspace (Local Config)

| Platform | Path |
|---|---|
| Windows | `%APPDATA%\navicat-rs\navicat-rs.json` |
| macOS | `~/Library/Application Support/navicat-rs/navicat-rs.json` |
| Linux | `$XDG_CONFIG_HOME/navicat-rs/navicat-rs.json` or `~/.config/navicat-rs/navicat-rs.json` |

> The database itself is whatever SQLite file you connect to; it is not stored in the config.

---

## 13. Environment Variables (Optional)

| Variable | Meaning |
|---|---|
| `NAVICAT_RS_THEME` | Startup theme: `light`/`dark`/`midnight`/`forest`/`sand`/`graphite` |
| `NAVICAT_RS_DEMO` | `1` opens sample query/tables; `all` opens all feature pages (screenshots/acceptance) |
| `NAVICAT_RS_TAB` | With demo, switch to the tab whose title contains this substring |

---

## 14. FAQ

**Need a Navicat account or license?** No. It opens straight to the main UI, no login/activation/trial prompts.
**Where is the data?** See "Workspace"; Windows is `%APPDATA%\navicat-rs\navicat-rs.json`.
**Can non-SQLite engines really connect?** SQLite is fully real, PostgreSQL uses the real protocol; others are connection config + offline demo DB.
**Text hard to read in dark themes?** Fixed — text color is contrast-based across all themes; report with a screenshot if any issue remains.
