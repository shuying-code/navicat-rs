## 诚实清单（本轮仍无法在离线环境落地的部分）

1. **除 PostgreSQL 外的跨引擎真实协议**（MySQL/MariaDB/Oracle/SQLServer/MongoDB/Redis/Snowflake/达梦/ODBC）：需要对应原生/纯 Rust 驱动与网络服务器。本轮已抽象 `realdb` 驱动层并以 PostgreSQL 跑通整条真实链路（连接测试 + 真实查询）；其余引擎保持"连接配置 + 离线演示 schema"，可按同一模式逐个接入驱动。**离线环境无对应服务器，无法端到端验证成功连接**，故如实保留。
2. **OS 级定时调度**（自动化）：本地任务列表 + 手动执行；未内置系统级计划任务触发器。
3. **真实大模型 AI**：本地启发式（解释/生成/优化），未接入远程/本地 LLM（遵守"全开放、不设配额"前提下可选接入）。
4. **存储过程/函数/序列/同义词结构编辑**：SQLite 不支持这些对象；索引/触发器/视图已可管理。其他引擎接入驱动后可在同一"对象管理"页扩展。
5. **系统文件选择对话框**：导入/导出/备份/数据泵使用手动路径输入（功能完整），未集成原生文件选择器。

## 结论

旧版差距清单中的 **1–16 项绝大多数已按文档逐条落地并复测**：对象管理、SQL 大纲/重构、模式分析、数据泵、模型设计器（概念/逻辑/物理 + 对比 + 同步）、查找于数据库、收藏/聚焦、可视化执行计划树、导入 JSON/SQL、传输列映射+过滤、内存库备份、HTML 导出、自动提交事务化均已实现；跨引擎真实连接已用 **PostgreSQL 真实网络协议**跑通整链路，其余引擎因离线无服务器而保留为"配置 + 演示 schema"，属于环境限制而非界面/逻辑缺失。
