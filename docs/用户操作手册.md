# navicat-rs 用户操作手册

> 适用版本：v0.1.0 及以上。
> 本手册面向最终用户，介绍启动、界面、连接、数据表、SQL 查询、设计与建模、数据搬运、运维工具与常见问题。
> 快速总览见仓库根目录 [README](../README.md)；变更见 [CHANGELOG](../CHANGELOG.md)。

---

## 1. 简介

navicat-rs 是一个用 **Rust + egui/eframe** 编写的**跨平台单文件**数据库管理桌面客户端，界面与工作流参考 Navicat Premium 18。
**所有功能全部免费开放，无登录、无试用、无授权/权限限制**；本地优先，不连接任何云端。

---

## 2. 安装与启动

### 2.1 Windows（推荐）

1. 从 [Releases](https://github.com/shuying-code/navicat-rs/releases) 下载 `navicat-rs` 可执行文件（或 zip）。
2. **双击运行**，无需安装（单文件绿色程序，内嵌中文字体，无缺字方框）。
3. 若被 SmartScreen 拦截：点「更多信息 → 仍要运行」。

### 2.2 macOS / Linux

macOS 使用 universal 二进制（Intel/Apple Silicon 通用），Linux 使用 x64 包（需系统 GUI 依赖）。GUI 需在有桌面环境时运行。

### 2.3 命令行参数

| 参数 | 说明 |
|---|---|
| （无） | 启动 GUI |
| `--selftest` | 无头运行功能自检，打印 `[PASS]/[FAIL]`，退出码 0=全通过 |

---

## 3. 界面总览

三区布局：**菜单栏 / 工具栏 / 标签栏 / 左侧连接与对象树 / 右侧功能页 / 状态栏**。

- **左侧对象树**：`连接 → 表 / 视图 / 备份 / 模型 / 用户`；可缩放（`− 100% ＋`、`Ctrl+滚轮`、设置页滑杆），可分组独立折叠。
- **多标签**：数据表、查询、设计、ER、构建器及各工具页并行打开，互不干扰。
- **多主题**：`查看 → 主题` 或 `设置 → 主题` 切换，选择持久化。

---

## 4. 首次使用

首次启动会自动创建「示例数据库 (SQLite)」（4 张表 + 1 个视图 + 演示数据）。

1. 左侧对象树双击「示例数据库」下的表即可浏览数据。
2. 顶部工具条可打开查询 / 设计表 / ER 图 / 查询构建 / 传输 / 导入 / 导出 / 备份 / 监控 / 图表 / 剖析 / AI 等全部页面。

---

## 5. 连接管理

- 新建连接：填写引擎、主机、端口、库名、用户、密码等（见 README「数据库后端」）。
- **SQLite**：完全真实（连接、查询、CRUD、DDL、脚本、外键、PRAGMA，`rusqlite` bundled）。
- **PostgreSQL**：真实网络协议（连接测试 + 真实查询）。
- 其余引擎（MySQL/MariaDB/Oracle/SQL Server/MongoDB/Redis/Snowflake/达梦/ODBC）：连接配置 + 离线演示 schema（界面 / 工作流完整）。

## 6. 数据表

- **浏览**：分页、过滤、排序（点击表头）。
- **编辑**：内联编辑单元格、增删行。
- **导出**：将当前表数据导出。

## 7. SQL 查询

- **Explain** 执行计划树。
- **SQL 美化**、SQL 大纲 / 重构建议、查询历史。

## 12. 工作区（本地配置）

配置与状态保存在各平台用户配置目录：

| 平台 | 路径 |
|---|---|
| Windows | `%APPDATA%\navicat-rs\navicat-rs.json` |
| macOS | `~/Library/Application Support/navicat-rs/navicat-rs.json` |
| Linux | `$XDG_CONFIG_HOME/navicat-rs/navicat-rs.json` 或 `~/.config/navicat-rs/navicat-rs.json` |

> 数据库本身由你连接的 SQLite 文件决定，不随配置保存。

## 13. 环境变量（可选）

| 变量 | 说明 |
|---|---|
| `NAVICAT_RS_THEME` | 启动主题：`light`/`dark`/`midnight`/`forest`/`sand`/`graphite` |
| `NAVICAT_RS_DEMO` | `1` 打开示例查询与表；`all` 打开全部功能页（截图/验收用） |
| `NAVICAT_RS_TAB` | 配合 demo，切换到标题包含该子串的标签页 |

## 14. 常见问题（FAQ）

**Q：需要 Navicat 账号或授权吗？**
不需要。启动即进主界面，无登录 / 激活 / 试用提示。

**Q：数据存在哪里？**
见「工作区」；Windows 为 `%APPDATA%\navicat-rs\navicat-rs.json`。

**Q：某个非 SQLite 引擎能真正连接吗？**
当前 SQLite 完全真实、PostgreSQL 为真实网络协议；其余为连接配置 + 离线演示库。

**Q：暗色主题下文字看不清？**
已修复，所有主题下文字按对比度取色；如仍有异常请附截图反馈。
