## 迭代过程中的关键修复

1. **网格行合并 Bug**：表格行循环外层误用 `ui.push_id(ri, …)`，导致 `egui::Grid` 认为所有单元格属于同一行而挤在一行。改为行循环直接 `ui.end_row()`，`query` 结果网格同步修复 → 行正确分列。
2. **中文缺字**：默认 egui 字体不含中日韩字形，界面出现方块。改为 `include_bytes!` 内嵌 `NotoSansSC-Regular.ttf` 并在启动时注入 → 中文/树/表格正常。
3. **编译环境**：`rusqlite(bundled)` 需 C 编译器，统一用 `vcvars64.bat` 初始化后再 `cargo build`；`egui` 必须与 `eframe` 同版本(0.29)。
4. **磁盘空间**：F: 仅约 4.6 GB，`.cargo/config.toml` 将 `target-dir` 指到 `C:\cargo-target\navicat`，避免撑爆 F:。
