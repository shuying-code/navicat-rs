# 功能矩阵与业务逻辑（Navicat Premium 18）

> 依据：`AppFeature*`（92）、`FormType*`（177 唯一）、`ac*`（4,787 唯一）、`cc*`（13）与插件 DLL 证据。
> 本文把"原程序能力域"映射到"复刻导航入口 / 页面"，并标注落地程度。
> 落地等级：**A=真实可用**（SQLite 真连真做）；**B=可交互**（UI 完整、离线演示数据、按钮有动作）；**C=占位**（页面/入口存在但能力受限）。

---

| Oracle | `ccORA`、`libobci.dll`+`instantclient_23_0` | 连接配置 + 演示 schema | B |
| SQL Server | `ccMSSQL`、`msodbcsql.msi` | 连接配置 + 演示 schema | B |

## 8. 云端（不实现，仅说明）

`AppFeatureCloud*`（Connection/Model/Project/ProjectMember/Query/Snippet/TableProfile/UserQuota/VirtualGroup/ChartsWorkspace/Pipeline…）属于**云端协作与配额**范畴。复刻按"本地优先、无云端依赖"原则**不接入**这些能力；相应本地替身（本地连接、本地模型、本地片段等）已覆盖。

## 9. 统计口径说明

- 92 个 `AppFeature*` 中，部分为形态/开关细分（如 `ExportTypeTextBase`/`ExportTypeAdvanced`、`Model*` 的多种建模视图、`ConnUseCase*`），本矩阵按"用户可感知能力域"归并。
- 177 个 `FormType` 中包含大量属性页（`*Property*`）与对话框；复刻以"主功能页 + 关键对话框"对齐，属性页以数据字典/设计器/设置等价表达。
- 4,787 个 `ac*` 动作中大量为同义/上下文动作；复刻以菜单/工具栏/右键高频动作对齐。
