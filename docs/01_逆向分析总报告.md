## 0. 摘要与关键结论

1. **`F:\navicat18_premium_cs_x64.exe` 不是主程序，而是安装包**。它把完整的 Navicat Premium 18 运行目录释放到磁盘。为拿到可分析的真实二进制，采用 per-user 静默安装（`/CURRENTUSER /VERYSILENT /DIR=F:\navicat_app`）得到 **`F:\navicat_app`**：**181 个文件 / 约 639.6 MB**，其中主程序 `navicat.exe` 约 **105.0 MB**。
2. **技术栈为 Delphi / C++Builder FireMonkey (FMX)**，不是 Electron/Qt。依据：符号与 RTTI 中出现 `TNavicatMainForm`、`TCM*Property_*`、`TQueryBuilderForm`、`TDeploymentFrame`、`FMX.Controls.*`、`vfContext*` 等 FMX 类；`libcc.dll`（158 MB）承载绝大部分 UI/业务渲染（FMX 运行时+界面控件）。`mozjs-115.dll` 说明内置 SpiderMonkey 用于脚本（自动化/SQL 脚本）。
3. **业务逻辑高度由统一特性枚举 + 表单枚举 + 动作集合驱动**：静态提取到 **92 个 `AppFeature*` 特性常量、177 个唯一 `FormType*` 表单类型、4,787 个唯一 `ac*` 动作**，以及 **13 类连接 `cc*`**（其中数据库引擎 11 种）。这构成了"功能 = 特性开关 + 表单 + 动作"的结构化证据链。
4. **原生插件化能力齐全**：`libxl.dll`（Excel 读写）、`libnpdf.dll`/`podofo.dll`（PDF）、`libncharts.dll`/`rescharts.dll`（图表）、`libqb.dll`（查询构建）、`libndataprofiling.dll`（数据剖析）、`libaggrpipe.dll`（聚合管道/Mongo）、`nparser.dll`/`dparser.dll`（SQL 解析）、`arrow.dll`/`parquet.dll`（列式数据）、`sqlite3.dll`、`libmariadb*.dll`、`libpq*.dll`、`libobci.dll`+`instantclient_23_0`（Oracle OCI）、`mongoc/bson`、`redis++/hiredis`、`krb5/gssapi`（Kerberos）等。
5. **登录 / 收费 / 会员门槛**：客户端内存在试用期与订阅相关字符串（`nlsTrialExpired`、`isInTrialPeriodNow`、`trialEnabled`、`license`、`subscription`、`Premium` 等）。但本地数据库操作（连接、查询、设计、导入导出等）的能力本身内置于本地，付费墙主要作用于**云端工作区/协作/额度**类功能。因此"解除限制"在复刻层等价于**完全不实现任何授权校验，所有功能默认开放**。
6. **本次复刻目标**：用 **Rust（egui/eframe）** 在 **F: 盘** 重建一个"同功能、同页面观感"的桌面前端；**所有原本付费/受限功能一律免费开放、无任何权限/授权设置**。

## 2. 解包与语料获取（可复现）

由于 `innoextract 1.9` 版本过旧、不支持该版本的 Inno Setup 格式，改为**直接运行安装包做 per-user 静默安装**，从而获得与原程序完全一致的运行目录（含全部 DLL 与资源），再进行静态分析：

```powershell
# per-user 静默安装到 F:\navicat_app（无需管理员权限）
Start-Process "F:\navicat18_premium_cs_x64.exe" `
  -ArgumentList "/CURRENTUSER /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /DIR=F:\navicat_app" -Wait
```

随后对 `F:\navicat_app\navicat.exe` 与关键 DLL 做字符串/符号提取，得到分析语料（存放于复刻工程外的分析工作目录）：

| 语料文件 | 内容 |
|---|---|
| `tokens.txt` | 类名、枚举、动作、连接类型等结构化标识（去重） |
| `actions_curated.txt` | 精选 `ac*` 动作清单 |
| `feature_keywords.tsv` | 按功能域聚合的关键词计数（Backup 724、Import 1343、Export 856、Chart 3244 …） |
| `strings_navicat.txt` / `strings_wide.txt` | ASCII / UTF-16 字符串全集 |

## 3. 结构化证据：功能 = 特性 + 表单 + 动作

### 3.1 AppFeature 特性枚举（92 个）

程序用一个 `AppFeature*` 枚举表达"某项能力是否属于 Premium/某个版本"。共提取 **92 个**，覆盖数据库引擎、数据工具、模型设计、云、AI 等。代表性条目（节选，完整见 `02_功能矩阵与业务逻辑.md`）：

```
AppFeatureMySQL / MariaDB / PostgreSQL / SQLite / Oracle / SQLServer /
Snowflake / MongoDB / Redis / Dameng           -- 数据库引擎
AppFeatureDataTransfer / DataSynchronization / StructureSynchronization /
DataPump / Backup / Import / Export            -- 数据搬运
AppFeatureQueryBuilder / BeautifySQL / SQLRefactor / CodeOutline /
VisualExplain / SchemaAnalysis / DataProfiling / DataDictionary -- 查询/分析
AppFeatureModelERDiagram / ModelConceptualModel / ModelLogicalModel /
ModelPhysicalModel(隐含) / ModelCompareWorkspace / ModelSyncModelToDB -- 模型
AppFeatureCharts / Report / Automation / AI / DataGeneration / DataMasking -- 增强
AppFeatureCloud* (十余项)                        -- 云端协作（复刻不实现云端）
```

### 3.2 FormType 表单类型（177 个唯一）

每个功能页对应一个 `<Xxx>Form`/`FormType`。共 **177 个唯一值**，是"页面清单"最直接的证据。代表性的表单（对应复刻页）：

`FormTypeMainForm / FormTypeConnectionForm / FormTypeTableDataForm / FormTypeQueryForm / FormTypeDesignForm(表设计) / FormTypeERDiagramForm / FormTypeQueryBuilderForm / FormTypeDataTransferForm / FormTypeImportWizardForm / FormTypeExportWizardForm / FormTypeBackupForm / FormTypeServerMonitorForm / FormTypeDataProfilingForm / FormTypeDataGenerationForm / FormTypeChartForm / FormTypeReportForm / FormTypeAutomationDesignForm / FormTypeUserManagerForm / FormTypeSnippetForm / FormTypeAIAssistantForm …`

### 3.3 动作集合（4,787 个唯一 `ac*`）

菜单/工具栏/快捷键统一走动作分发（`acXxx`）。共 **4,787 个唯一动作**，覆盖连接、对象操作、导入导出、同步、模型、查询、视图切换等。动作规模说明 Navicat 的交互面非常广；复刻以"高频主路径动作"为核心，其余以等价页面入口覆盖。

### 3.4 连接类型（13 类 `cc*`）

```
ccMYSQL  ccMARIADB  ccPGSQL  ccSQLITE  ccORA  ccMSSQL  ccMONGODB
ccREDIS  ccSNOWFLAKE  ccDAMENG  ccODBC  (+ ccII / ccNQ 为内部连接信息类目)
```

对应 11 种数据库引擎：**MySQL、MariaDB、PostgreSQL、SQLite、Oracle、SQL Server、MongoDB、Redis、Snowflake、达梦(Dameng)、ODBC**。

## 5. 与"本地能力"相关的业务逻辑要点

- **连接与对象树**：连接 = 一个 profile（引擎类型 + 主机/端口/库/凭据/SQLite 路径）。连接成功后枚举 schema 下 表/视图/索引/触发器/存储过程/函数/序列/同义词 等对象，形成左侧对象树。复刻以 SQLite 为真实后端，其余引擎用"连接配置 + 演示 schema"做离线可交互。
- **表数据网格**：分页、排序、按列过滤、内联编辑、增删行；底层按主键/rowid 定位更新。
- **SQL 编辑器**：多语句脚本、结果集网格、执行耗时、影响行数、错误提示。
- **表设计器**：列名/类型/非空/主键/默认值编辑并落地 DDL。
- **ER 图**：表→实体卡、外键→连线，自动布局。
- **数据搬运链**：传输(Transfer)、导入(Import)、导出(Export)、备份(Backup)、同步(Synchronization)、数据泵(DataPump)。
- **分析工具**：数据剖析(Profiling)、数据字典(Dictionary)、服务器监控(Monitor)、图表(Chart)、报表(Report)、可视化执行计划(Visual Explain)、模式分析(Schema Analysis)。
- **增强工具**：数据生成(DataGeneration)、数据脱敏(DataMasking)、AI 助手、代码片段(Snippet)、自动化(Automation)。

上述每一项在复刻工程中都有对应可打开页面（见 `04`、`05`、`06`、`07`）。

## 6. 收费 / 权限门槛的结论

- 客户端含有试用/订阅/许可证判定字符串，但**能力本体在本地**；付费墙聚焦"云端额度/协作/高级治理"。
- 复刻策略：**不实现任何登录、许可证、试用期、配额、角色权限判断**；所有页面与操作默认可用。详见 `03_收费与权限去除说明.md`。

## 7. 分析局限

- 未能对 `navicat.exe`/`libcc.dll` 做完整反编译级还原（体积大、FMX RTTI 结构复杂）；本报告以**符号/字符串/枚举/插件 DLL** 作为可交叉验证的结构化证据，而非逐函数反编译。
- 云端（Cloud*）、团队协作、部分专有引擎协议未纳入本地复刻的"真连真用"范围，仅保留等价 UI 入口与离线演示。
