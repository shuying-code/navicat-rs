# navicat-rs

**Кроссплатформенный десктопный клиент управления базами данных одним файлом**, написанный на **Rust + egui/eframe**; UI и рабочий процесс вдохновлены Navicat Premium 18.
**Все функции полностью открыты и бесплатны: без логина, пробного периода и ограничений лицензии/прав.**

## Почему «без ограничений»

Платные/логин-ограничения Navicat относятся в основном к **облачным / подписочным** функциям (облачная синхронизация, командная работа, облачная автоматизация и т. д.). Этот инструмент реализует только **независимое от облака локальное** управление БД, поэтому не требует аккаунта, оплаты и квот. По замыслу ограничения на логин / подписку / лицензию удалены; все локальные функции доступны безусловно.

## Возможности

- **Таблицы**: постраничный просмотр, фильтрация, встроенное редактирование, добавление/удаление строк, сортировка (клик по заголовку), экспорт.
- **SQL-запросы**: выполнение нескольких выражений, `Ctrl+Enter`, результаты в нескольких сетках, время / число строк, дерево плана Explain, форматирование SQL, контур SQL / подсказки рефакторинга, история запросов.
- **Проектирование и моделирование**: дизайнер таблиц (правка столбцов → DDL), ER-диаграмма, конструктор запросов, дизайнер моделей (концептуальная/логическая/физическая · реверс-инжиниринг · сравнение · синхронизация).
- **Перемещение данных**: передача данных (маппинг столбцов + WHERE), синхронизация данных/структуры, мастер импорта (CSV/JSON/SQL), мастер экспорта (CSV/JSON/SQL/HTML), data pump.
- **Эксплуатация и доп. возможности**: резервное копирование/восстановление (вкл. in-memory БД `VACUUM INTO`), монитор сервера, профилирование, анализ схемы, генерация данных, маскирование, графики, словарь данных, отчёты.
- **Объекты и поиск**: управление объектами (индекс/триггер/представление), поиск по базе (поиск значений столбцов по всем таблицам), масштабирование дерева объектов и сворачивание групп.
- **Прочее**: AI-ассистент, автоматизация / планировщик задач, сниппеты кода, пользователи и права (всё открыто), настройки (мультитемы / масштаб дерева / автокоммит / подтверждение удаления).
- **Мультитемы**: светлая / тёмная / полночь / лес / песок / графит; текст тела и кнопок остаётся контрастным и читаемым в любой теме.

## GUI

- **Чистый Rust + egui/eframe**: один exe, без WebView, запуск двойным щелчком; встроенные CJK-шрифты, без «квадратиков».
- **Трёхзонный макет**: строка меню / панель инструментов / вкладки / слева подключение и дерево объектов / справа страницы функций / строка состояния.
- **Дерево объектов**: подключение → таблицы / представления / резервные копии / модели / пользователи; масштабирование (`− 100% ＋`, `Ctrl+колесо`, ползунок в настройках), сворачивание групп.
- **Мультивкладки**: таблицы, запросы, дизайн, ER, конструктор и страницы инструментов открываются параллельно.
- **Мультитемы**: переключение через `Вид → Тема` или `Настройки → Тема`, выбор сохраняется.

## Сборка

Требуется Rust 1.75+ (рекомендуется stable).

```bash
cargo build --release
```

### Windows (MSVC)

```powershell
# Требуются Visual Studio Build Tools (C++ и Windows SDK)
cargo build --release
```

### macOS

```bash
xcode-select --install   # может понадобиться при первом запуске
cargo build --release
```

### Linux (Debian/Ubuntu)

```bash
sudo apt-get install -y build-essential pkg-config \
  libxkbcommon-dev libgtk-3-dev libgl1-mesa-dev \
  libx11-dev libxi-dev libxrandr-dev libxcursor-dev libxinerama-dev \
  libxcb-render0-dev libxcb-shape0-dev libxcb-xfixes0-dev
cargo build --release
```

## Использование

```bash
navicat-rs              # запуск GUI
navicat-rs --selftest   # безголовый самотест (движок SQLite + ключевые функции, 22 проверки)
```

При первом запуске автоматически создаётся «Демо-база (SQLite)» (4 таблицы + 1 представление + демо-данные). Двойной щелчок по таблице в дереве объектов открывает её; верхняя панель инструментов открывает запрос / дизайн таблицы / ER / конструктор / передачу / импорт / экспорт / резервное копирование / монитор / графики / профилирование / AI и все прочие страницы.

## Рабочая область (локальная конфигурация)

Конфигурация и состояние (подключения, история, избранное, тема, настройки) хранятся в пользовательском каталоге конфигурации каждой платформы:

| Платформа | Путь |
|---|---|
| Windows | `%APPDATA%\navicat-rs\navicat-rs.json` |
| macOS | `~/Library/Application Support/navicat-rs/navicat-rs.json` |
| Linux | `$XDG_CONFIG_HOME/navicat-rs/navicat-rs.json` или `~/.config/navicat-rs/navicat-rs.json` |

## Бэкенды баз данных

| Движок | Статус |
|---|---|
| SQLite | **Полностью реальный**: подключение, запросы, CRUD, DDL, скрипты, внешние ключи, PRAGMA (`rusqlite` bundled, кроссплатформенно) |
| PostgreSQL | **Реальный сетевой протокол**: тест подключения + реальные запросы (чистый Rust `postgres`) |
| MySQL / MariaDB / Oracle / SQL Server / MongoDB / Redis / Snowflake / Dameng / ODBC | Конфигурация подключения + офлайн демо-schema (UI/рабочий процесс полны; слой драйверов абстрагирован, добавляется по `src/realdb.rs`) |

| Аргумент | Описание |
|---|---|

| Переменная | Описание |
|---|---|
| `NAVICAT_RS_THEME` | Тема при запуске: `light`/`dark`/`midnight`/`forest`/`sand`/`graphite` |
| `NAVICAT_RS_DEMO` | `1` открывает демо-запросы и таблицы; `all` открывает все страницы функций (для скриншотов/приёмки) |

## Частые вопросы (FAQ)

**В: Нужен аккаунт или лицензия Navicat?** Нет. Приложение сразу открывает главный UI; без логина / активации / пробных подсказок.

**В: Где хранятся данные?** См. «Рабочая область»; Windows — `%APPDATA%\navicat-rs\navicat-rs.json`; сама БД — это ваш подключаемый файл SQLite.

**В: Почему бинарник macOS собирается в CI?** Эта машина — Windows; универсальный бинарник macOS создаётся GitHub Actions `macos-latest` (см. `build.yml`).

**В: Может ли не-SQLite движок реально подключиться?** SQLite полностью реален, PostgreSQL использует реальный сетевой протокол; остальные — конфигурация + офлайн демо-БД, расширяемо по `src/realdb.rs`.
